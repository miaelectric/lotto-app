# 🎱 로또 번호 자동 추천

로또 6/45 번호를 자동으로 추천해 주는 정적 웹 앱이에요. 빌드 과정 없이 HTML, CSS, JS만으로 동작해요.

## 기능
- 1~5게임 자동 추천 (`crypto.getRandomValues` 기반 균등 난수)
- 고정수(최대 5개) · 제외수 지정
- 번호대별 공 색상 (1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록)
- 게임별 번호 복사
- 최근 추천 기록 20개 (브라우저 localStorage에만 저장)
- 라이트/다크 모드, 모바일 대응

## 실행
`index.html`을 브라우저로 열면 돼요.

## 배포
Vercel에서 이 저장소를 Import하면 별도 설정 없이 배포돼요.

> 번호는 무작위로 뽑으며 당첨 확률을 높여 주지 않아요.
